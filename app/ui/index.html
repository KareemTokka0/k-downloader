Settings

Downloads folder
Projects folderOptional. A folder of project folders; pick a project below and downloads land inside it (01 Brief, 02 References, 03 Footage, 04 Photos, 05 Exports) instead of Downloads.
Cache folderPartial downloads, speech models and the GPU engine. Move it to a bigger drive if you like; the helper restarts.
Source healthEvery search site is tried once a day with a fixed phrase. A site that used to answer and now gives nothing is marked broken.
Start with WindowsRuns quietly in the tray at sign-in, so the browser button and Claude Code always work.
Chrome extensionThe Download button on YouTube, Facebook, Instagram and more, plus a download manager for every file you save in Chrome. Open chrome://extensions, turn on Developer mode, press Load unpacked and pick this folder. Then click the K icon in Chrome and press Connect. After an update, press the reload arrow on the extension's card.
Userscript (optional)The same Download button for browsers without the extension, through OrangeMonkey or Tampermonkey.
ClaudeRegistered automatically in Claude Code and the Claude desktop app every time K Downloader starts. Restart Claude once after installing.
App updatesPoint this at the team's shared folder (or a web address) that holds the newest Setup file and latest.json. The app checks every 6 hours and installs quietly at sign-in.
GPU speech engineChecking the graphics card...
Download engineUpdates itself once a day.
Image sourcesNo keys needed: the app reads each site's own search page in a hidden browser window. Green sources (Pexels, Pixabay, Unsplash) are free to use; Openverse and Wikimedia show the licence per photo; the grey sources (Google, Bing, Yandex, Pinterest) are reference only and must never be published; paid stock sites are left out on purpose. Sign in to Pinterest or Google on the Browser page to get their full results. A site that asks to check you are human opens a window once.
Pairing codeOnly needed if the browser script asks for it.
